# 单面局部去高光提示词

先观察原图并保存源坐标二值高光蒙版，再填写位置。每面只有一个主原图；模型输出仅作为补片候选。

```text
Use case: precise-object-edit / lighting-weather
输入：这台手机的原始{面名}照片，唯一的结构、颜色和纹理依据。
任务：只去除{具体坐标/归一化位置、形状}的灯条高光，将其接续成紧邻的原有{颜色、深浅、纹理}。该处是打光反射，不是真天线或贴纸。
保持：原始方向、完整主体、{原宽高比}和结构位置；附近{孔洞/按键/接缝/天线/划痕}保持原样。贴纸{位置}禁止重绘。
补片需与原图旁边的原始明暗吻合，不做整面柔光、统一材质或色彩，不抬亮暗部，不锐化、磨皮、美化、翻新，不新增划痕或结构。
延续旁边同一表面的纹理尺度、方向和细密程度。不能填成平滑雾面、云斑、横带或具有独立明暗的竖块。对于窄长照片优先使用包含足够正常材质的局部裁图，避免整面重绘造成纹理位置漂移。
只改变确认的高光。已过曝遮住的信息仅续接邻近基础材质，不猜测隐藏瑕疵。
输出：一张同方向、完整主体的透明PNG候选；可以有透明画布留白，但主体比例不变。最终只从候选取高光蒙版内的像素，原图其他像素会逐像素保留。
```

每面首次仅生成一次。明显补片不可用或几何错误可从原图重试一次，不把轻微差异转化为整面重绘。提示词无法保证区域外原像素，必须运行 composite_highlights.py。
